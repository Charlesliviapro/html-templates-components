# HTML Components Library

A comprehensive collection of reusable HTML components for building modern websites.

## 📦 Components Included

### Navigation Bars (3 variants)
- **navbar-basic.html** - Simple navigation with logo and links
- **navbar-dark.html** - Dark-themed navigation bar
- **navbar-with-cta.html** - Navigation with call-to-action button

### Footers (3 variants)
- **footer-basic.html** - Multi-column footer with links and contact info
- **footer-simple.html** - Minimal single-line footer
- **footer-social.html** - Footer with social media links

### Cards (4 variants)
- **card-basic.html** - Simple card with header, body, and footer
- **card-image.html** - Card with top image
- **card-feature.html** - Icon-based feature card
- **card-product.html** - Product/pricing card with image and CTA

### Forms (4 variants)
- **form-contact.html** - Contact/inquiry form with multiple fields
- **form-login.html** - User login form with remember me option
- **form-signup.html** - User registration form with validation hints
- **form-newsletter.html** - Email subscription form

### Heroes & Features (4 variants)
- **hero-basic.html** - Centered hero section with title and CTAs
- **hero-image.html** - Hero with side-by-side image layout
- **hero-cta.html** - Hero focused on single call-to-action
- **feature-grid.html** - Grid of feature items with icons

## 🎨 Styling

All components use a single CSS file (`styles/components.css`) that includes:
- Modern, clean design
- Fully responsive layouts
- CSS custom properties for easy customization
- Smooth transitions and hover effects
- Mobile-first approach

## 🚀 Quick Start

1. Link the CSS file in your HTML:
```html
<link rel="stylesheet" href="styles/components.css">
```

2. Copy any component HTML from the `components/` directory

3. Customize the content and styling to match your needs
