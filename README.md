# HTML Templates Components

A comprehensive library of reusable HTML components for building modern websites quickly and efficiently.

## 🚀 Quick Start

1. **Open the index page** to browse all available components:
   ```
   open index.html
   ```

2. **View the complete example** to see how components work together:
   ```
   open examples/complete-landing-page.html
   ```

3. **Read the documentation** for detailed usage instructions:
   ```
   open notes.md
   ```

## 📦 What's Included

### Navigation Bars
- **Standard Navbar**: Clean, sticky navigation bar
- **Transparent Navbar**: Perfect for hero overlays
- **Dark Navbar**: Modern dark theme

### Footers
- **Simple Footer**: Minimal footer for landing pages
- **Multi-Column Footer**: Comprehensive footer with link sections
- **Social Media Footer**: Footer with social icons

### Cards
- **Basic Card**: Simple content card
- **Image Card**: Card with featured image
- **Product Card**: E-commerce product display
- **Profile Card**: Team member/user profile
- **Card Grid**: Responsive grid layout

### Forms
- **Login Form**: User authentication
- **Signup Form**: User registration
- **Contact Form**: Get in touch form
- **Search Form**: Inline search component

### Hero Sections
- **Full-Width Hero**: Gradient hero with CTAs
- **Hero with Background**: Background image hero
- **Split Hero**: Two-column layout
- **Features Section**: Feature showcase grid

## 🎨 Features

- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ No JavaScript dependencies
- ✅ Modern CSS with Flexbox and Grid
- ✅ Clean, semantic HTML5
- ✅ Easy to customize
- ✅ Ready to use
